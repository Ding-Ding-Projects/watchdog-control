State inventory

Every session state, told honestly

running · waiting for input
Enter a value for Name:

The composer label changes to Send as input. Text goes to the running program's standard input and appears as an input entry.

disconnected · reconnecting
Lost contact with the controller. Retrying in 4 s.

The last known state stays visible with a grey unknown badge. A command is never shown as finished while disconnected. Output resumes from the last received entry.

stopped by you
Session stopped · process tree ended · 20:14:02

Stop ends the shell and every process it started. The transcript stays readable; Start again opens a fresh session with the same shell.

exited
Shell exited · code 0 · 20:20:41

Shown when the shell ends by itself, for example after exit. The real exit code is reported.

expired
Stopped after 15 min without activity

Idle sessions stop to free resources. Sessions also end when the controller restarts; the page says so instead of reconnecting forever.

output limit reached
Older output dropped · 2 MB kept

The oldest entries are removed to stay within the limit and a marker shows where. The session keeps running.

unsupported

Full-screen console programs (editors, top, interactive installers) need a real terminal. This page streams text only, so those programs may wait or misbehave. Stop the session if one hangs.

signed out

Every terminal request needs the owner session. When it expires the page returns to sign in; sessions keep running until they stop or expire.

Inert output

All commands and output are plain text. HTML-like text, escape sequences and links are shown as characters and never become live elements.
