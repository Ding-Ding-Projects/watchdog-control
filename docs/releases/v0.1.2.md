# Watchdog Control v0.1.2

This release carries the setup progress-save fix. Each save writes through its own uniquely named temporary file before atomically replacing the saved progress record, avoiding collisions when setup work reports progress concurrently.

The portable setup executable includes `compose.yaml` and validates its checksum against the published release manifest. When a local container engine and the selected host settings are already ready, the welcome screen can start Watchdog Control directly without installing the setup executable or additional host software.

The guided prerequisite setup remains available for computers where the container engine is not ready. It retains the existing native consent, recovery, and host-power boundaries.
