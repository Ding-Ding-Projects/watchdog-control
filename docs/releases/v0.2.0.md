# Watchdog Control v0.2.0

This release adds Slop Machine remote control and redesigns every interface as a command centre.

## Slop Machine remote control

The new **Slop Machine** page drives the `codex` command-line tool on a paired Windows computer:

- a status check that reports the tool version, sign-in state, and remote control availability;
- device-code sign-in assist that shows the sign-in page, the one-time code, and a countdown;
- remote control start and stop;
- a phone pairing code for the ChatGPT phone app;
- sign-out after an exact typed phrase.

Every command is fixed in the agent. By default the tool runs as the Windows user signed in at the
console. One-time codes stay in controller memory until they expire and are redacted from operation
records, the audit log, exports, and the controller data file.

## Command centre redesign

The dashboard, setup assistant, and documentation site share a new design with a host radar, live
telemetry, animated gauges, view transitions, a command palette, context menus, a regex builder on
every search, a notification centre, and settings for language, theme, accent colour, text size,
contrast, motion, focus modes, narration, and sounds. Fonts are bundled. Reduced motion removes
every animation.

## Verification state

The source builds, and a local development controller passed an end-to-end check of the remote
flow. The dashboard was exercised in a browser. Running the remote operations and the redesigned
setup assistant on a Windows host has not been verified yet. This release also carries the v0.1.2
setup progress-save fix.
