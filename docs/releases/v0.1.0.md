# Planned release contents: Watchdog Control v0.1.0

**Release status: not published.** This document describes the intended normal release contents.
Its downloads are unavailable until a matching non-draft release is created and verified.

The planned release provides the authenticated host-management dashboard, typed LAN API, Windows
host agent, tracked container deployment, and the portable setup assistant.

## Downloads

- `WatchdogControlSetup.exe` is planned as a self-contained single-file Windows setup assistant. It checks and installs
  supported prerequisites, pulls the release-pinned image, configures persistent storage and
  TLS pairing, starts the named Compose service, and verifies its health and LAN address.
- `watchdog-agent-win-x64.exe` is planned as the optional Windows host agent. Installing the LocalSystem
  service requires the operator's explicit choice and native administrator consent.
- `watchdog-control-image-linux-amd64.tar` is planned as the container image archive. The same image is
  published to GitHub Container Registry by immutable digest.
- `compose.yaml`, `host.bat`, `host.ps1`, and `.env.example` are planned as the tracked host controls and
  credential-free configuration sample.
- `watchdog-release-manifest.json` will bind the source commit, version, image digest, archive hash,
  service paths, and health endpoint.
- `SHA256SUMS.txt` will list the SHA-256 checksums for every other release asset.

The Windows files are unsigned. Windows may show an unknown-publisher or SmartScreen warning.
No public certificate authority, signature, or authenticity claim is provided.

No tests or lint ran in the build workflow. Build and publication success do not establish a
live host installation, remote LAN reachability, or tested host-operation behavior. Review the
security and setup documentation before pairing a host.
