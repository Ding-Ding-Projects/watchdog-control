# Watchdog Control v0.1.0

This normal release contains the authenticated host-management dashboard, typed LAN API, Windows
host agent, tracked container deployment, and portable setup assistant. The release workflow
publishes its container image by immutable digest and attaches the matching image archive.

## Downloads

- `WatchdogControlSetup.exe` is a self-contained single-file Windows setup assistant. It checks and installs
  supported prerequisites, pulls the release-pinned image, configures persistent storage and
  TLS pairing, starts the named Compose service, and verifies its health and LAN address.
- `watchdog-agent-win-x64.exe` is the optional Windows host agent. Installing the LocalSystem
  service requires the operator's explicit choice and native administrator consent.
- `watchdog-control-image-linux-amd64.tar` is the container image archive. The same image is
  published to GitHub Container Registry by immutable digest.
- `compose.yaml`, `host.bat`, `host.ps1`, and `.env.example` provide the tracked host controls and
  credential-free configuration sample.
- `watchdog-release-manifest.json` binds the source commit, version, image digest, archive hash,
  service paths, and health endpoint.
- `SHA256SUMS.txt` lists the SHA-256 checksums for every other release asset.

The Windows files are unsigned. Windows may show an unknown-publisher or SmartScreen warning.
No public certificate authority, signature, or authenticity claim is provided.

The release workflow runs the product build and packaging entrypoints; it does not run tests or
lint. Its timing note reports the workflow run start and normal release publication time, plus
elapsed time to publication. It does not claim the full workflow has completed at the release
publication timestamp. Build and publication success do not establish a live host installation,
remote LAN reachability, or tested host-operation behavior. Review the security and setup
documentation before pairing a host.
