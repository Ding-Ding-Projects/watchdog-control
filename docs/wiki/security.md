# Security and identity

**State: Planned.** Host identity, user authentication, and server-side authorization are required before host management is ready. LAN membership alone does not establish trust.

The product must keep credentials and certificates out of browser-readable storage and tracked source. Logs and errors must not reflect sensitive request content.

Pairing, certificate trust, identity recovery, and revocation flows are not implemented. The final protocol and supported host matrix still need review.
