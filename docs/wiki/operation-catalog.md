**State: Planned.** Every host operation must have a stable identifier, strict parameter schema, permission checks, bounded execution, and an auditable outcome.

Free-form shell text, arbitrary executables, and caller-selected paths are prohibited. The final operation inventory and API schemas are not yet defined.
