# Project overview

**State: Planned.** Watchdog Control is planned as a LAN-scoped management dashboard for Windows hosts. This chapter describes intended scope, not a released product.

The project plans to surface health, services, processes, event logs, storage, network state, updates, firewall state, and carefully confirmed power actions. Every capability remains planned until a release and runtime evidence confirm it.

The documentation site and the future dashboard are separate surfaces. Reading this page does not connect to or control a host.
